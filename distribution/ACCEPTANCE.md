# Windows 候选实机验收

适用于对应完整安装包。版本、源码提交和运行载荷摘要以包内清单为准；当前候选与旧版本、回退基线分别记录，不再手填旧的 beta.7 等版本号。本页不表示任何项目已经通过。

## 先记录环境和证据

使用 Windows 11 x64、64 位 Python 3.10+（含 Tkinter）与 Windows PowerShell。在已指定的测试机上，以中文和空格路径创建隔离目录。保存完整 ZIP 的 SHA256、candidate-manifest.json 的源码提交、Python/系统版本、缩放和屏幕数。记录是否另一台物理电脑；远程窗口、同机新目录和 CI 都不能当作异机验收。

不要选择日常安装目录、插件缓存或有其他文件的目录。保留账户、会话、主题、指标和位置偏好；测试只停止本次隔离安装拥有的进程。未获得窗口身份的进程不能按名字批量结束。旧资产、备份、个人设置和历史库不覆盖、不清理。

## 安装、升级与回退

1. **新装。** 完整解压候选；运行“安装内测版.cmd”，或传入明确的空测试目录。启动目标目录的“启动统计条.cmd”，确认当前版本和本机原生窗口可见。
2. **真实旧版升级。** 将锁定的公开 beta.10 完整包解压到另一目录，用它的 install.ps1 和显式 `-InstallRoot` 安装到独立的“升级 含空格”目录。先启动旧版本，记录其进程身份和状态。再对这个受管测试目录运行新候选的 install.ps1；确认旧所属进程退出、版本指针更新，新版本可启动。不能只换元数据或用夹具代替旧版。
3. **保留数据。** 在旧版目录放入隔离测试偏好和已知历史样本，保存安装/回退边界的文件摘要。安装器应保持设置字节；应用启动可能重排 JSON，此时逐项比较值和未知字段。对历史库检查原有行和 SQLite 完整性，不以数据库文件大小相同当作通过。
4. **回退和再升级。** 在同一测试目录预检回退，再运行“回退上一版.cmd”，启动后应为固定 beta.6；重新运行当前候选安装器后应回到 candidate-manifest.json 中的版本。每一步核对原生窗口、设置、历史和退出回收。
5. **失败保护。** 仅在候选副本与隔离安装中测试缺少 Python、载荷缺失、回退包摘要不符、同版本不同内容、已安装文件被改动。应在停止现有进程或更新指针前拒绝；记录拒绝原因及原文件仍在。修正输入后重新安装可恢复。

默认“安装内测版.cmd”使用独立候选目录；直接调用 install.ps1 时始终显式给出 `-InstallRoot`。beta.6 是固定恢复版本，不包含后续内存修复，不能将其作为新版本长测结论。

## 实际窗口和交互

在真实缩放下操作并检查截图，原生加载冒烟检查或自动测试不能替代本节。截图保存在本机，分享前去除账户、会话标题和路径。

- 检查原生背景的圆角、透明度、裁剪、拖动和退出；不支持合成或系统关闭透明效果时单独记录原因，不擅自改变系统偏好。
- 桌面悬浮和输入框上方两种模式分别检查展开/收起、拖动、面板跟随、快速切换会话、侧栏收回恢复和宿主失活。确认没有沿用旧会话数据。
- 浅色/深色背景及目标缩放下检查文字、下拉、返回、悬浮详情，包含禁用、选中和键盘焦点。短屏检查滚动和溢出；没有相应屏幕条件就记未测试。
- 指标排序先正常保存一次，再拖动后按 Esc 取消；恢复原顺序且程序仍运行。会话选择与自定义时间弹窗取消后原设置保持。
- 在已登录的真实工作会话中确认生成和中断后的 TPS、额度与本地记录新鲜度；缺失和无单位值按实际来源显示，不造数。没有真实工作上下文则该项未测试。
- 在两种模式持续运行并记录时长、所属进程组资源、辅助进程轮换和退出后残留。采样缺口保留，不能把短时检查写成整夜通过。
- 取得当前工作可安全暂停的确认后再进行实际睡眠/唤醒；检查位置、会话和额度恢复。多屏与混合 DPI、另一台物理电脑各自记录，未执行不得勾通过。

## 记录方式

运行 acceptance 目录中的“收集验收结果.cmd”，非默认测试目录可作为第一个参数传入。它只输出白名单环境和运行状态，不会上传，也不代填视觉或手动结果。先查看输出再反馈。

从包内 RESULTS.json 复制一份到验收目录，逐项填 `passed`、`failed` 或 `not_run`，补充包的 SHA256、机器类型、实际环境、时间、复现步骤和本机截图位置。失败及未执行项原样保留；原始 ZIP 和其中初始记录保持不变。验收记录不能单独授权公开发布，CLI 保持不发布。
