# Codex Pulse

Resolve the plugin root two directories above this file. Read the Windows product version from plugin.json in that root; do not infer it from this skill title. Windows requires Python 3.10+ with Tkinter and Windows PowerShell; no API key or third-party Python package. Mac currently has a shared data backend and an implementation plan, not a released native UI.

Use the existing process when its creation identity and heartbeat are healthy. A saved running flag alone is insufficient. Use runtime_state.health and verify visible/native_visible separately. Never guess a conversation from the most recently modified file; automatic following accepts only an unambiguous current navigation title. Fixed statistics require a user-selected identity.

Start through launch.py, which supervises the strip and records real exit state. Detached Windows helpers use Start-Process -WindowStyle Hidden. Review instances are isolated validation aids and do not prove normal foreground behavior. Do not stack a second ordinary strip.

Preserve account, binding, theme, font size, metrics, order, expanded state and both placement preferences. Private installer pointers can resolve Windows Store LOCALAPPDATA redirection; never package those pointers, settings, raw logs or databases.

Read UI_RULES.html for UI work. Logo click only expands/collapses; dragging moves. Display mode only changes placement. Data hover opens read-only details. Right-click Logo or use the overflow control for settings. Escape cancels drag/menu/dialog or closes the focused settings panel; it must never exit the whole strip. Native widgets and GDI rendering use the same family, preferring Alibaba PuHuiTi and otherwise bundled Noto Sans SC.

Use the Windows package installer for managed installs/upgrades. It verifies current files and the pinned beta.6 recovery archive before stopping the owned process. It preserves data and old files. Never roll back to known-bad beta.5 or bypass drift checks. See BETA_GUIDE.md for supported installation structures, recovery and shutdown. A portable installation does not change global plugin registration by itself.

Account data is read-only. Do not log in, read authentication files, consume reset cards or initiate model requests through the quota backend. Missing values, true zero, stale account data and incomplete local coverage are separate states. Never fabricate currency units or interpolate missing usage intervals.

During verification operate the real current window, compare screenshots and preserve user edits. Tests, fixture windows and a started child are preparation evidence; report actual installed version, process identity and visual scope. Public/demo images use synthetic data and must be labelled accordingly.

No commit, push, publish, share, global plugin update or release without the user's explicit scope authorization. Local implementation, validation and a reviewable candidate do not imply permission to publish.
